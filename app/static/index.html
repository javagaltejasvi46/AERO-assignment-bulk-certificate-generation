API Endpoints Reference

RESTful specification implemented in FastAPI

POST /api/jobs 202 Accepted

Accepts a bulk recipient list, validates input, and spawns an asynchronous worker thread.

curl -X POST http://localhost:8000/api/jobs \
  -H "Content-Type: application/json" \
  -d '{
    "recipients": [{"name": "Alice Johnson", "email": "alice@domain.com"}],
    "course_name": "AI Systems",
    "issuer_name": "Tech Academy"
  }'
GET /api/jobs/{job_id} 200 OK

Returns real-time progress metrics (completed, failed, total) and nested certificate details.

GET /api/jobs/{job_id}/download 200 Streaming ZIP

Dynamically compresses all generated PDFs into an in-memory ZIP stream for bulk download.

GET /api/certificates/{cert_id}/download 200 PDF File

Returns the standalone ReportLab PDF for an individual certificate.

GET /api/jobs 200 OK

List all historical jobs with offset/limit pagination.
